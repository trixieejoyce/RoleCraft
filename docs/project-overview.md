# RoleCraft — Project Overview

## 1. Project Title

**RoleCraft: AI-Assisted Resume-to-Job Matching and Application Tailoring System**

## 2. Description

RoleCraft is a web-based application that helps users evaluate and
improve the alignment between their resume and a target job posting.

The application analyzes resume information and job requirements,
identifies matching and missing qualifications, and provides
job-specific recommendations.

The system also provides AI-assisted resume tailoring and cover letter
generation based on the user's existing qualifications and the target
job posting.

## 3. Problem

Job seekers frequently use the same resume when applying to different
positions. As a result, relevant qualifications, skills, experiences,
and job-specific keywords may not be sufficiently emphasized.

Applicants may also have difficulty determining which job requirements
they already satisfy and which qualifications they may need to improve.

## 4. Proposed Solution

RoleCraft provides a centralized platform where users can upload their
resume and provide a job description.

The system analyzes both sources and produces:

- Job-fit analysis
- Skill matching
- Skill-gap identification
- Keyword analysis
- ATS-oriented recommendations
- Resume tailoring suggestions
- Job-specific cover letter

## 5. Target Users

- Students
- Intern applicants
- Fresh graduates
- Entry-level job seekers
- Career changers
- General job applicants

## 6. AI Role

AI will be incorporated selectively rather than being responsible for
the entire application.

AI will primarily handle contextual interpretation and generation,
while conventional programming will handle validation, database
operations, calculations, file management, and other deterministic
processes.

## 7. Initial Scope

The first version will support:

- PDF resume uploads
- Job description copy-and-paste
- Resume analysis
- Job analysis
- Resume-job matching
- Skill-gap analysis
- ATS-oriented analysis
- Resume tailoring
- Cover letter generation

## 8. Out of Scope

The initial version will not include:

- Direct LinkedIn integration
- JobStreet integration
- Indeed integration
- Upwork integration
- OnlineJobs.ph integration
- Automated job application submission
- Guaranteed ATS scoring
- Automated job applications
